# Accounts Form (Vue 3)

Тестовое задание для позиции Vue Frontend Developer.

## Стек
- Vue 3 (Composition API)
- TypeScript
- Pinia
- Element Plus

## Функциональность
- Управление списком учетных записей
- Поддержка типов: LDAP / Локальная
- Валидация обязательных полей
- Сохранение данных в localStorage
- Восстановление данных при перезагрузке страницы

## Запуск проекта
```bash
pnpm install
pnpm dev
